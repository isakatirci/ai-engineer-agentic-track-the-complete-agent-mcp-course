3. Hedef: Junior Geliştirici İçin "Sıfırdan Hero" Ne Demek?

Başlangıç Profili [Öğretim tasarımı]

Öğrenci temel programlama bilgisine sahip bir junior geliştiricidir (hiç programlama bilmeyenler için önce Modül 0: Hazırlık Modülü tamamlanmalıdır). Başlangıçta şu alanlarda sıfır seviyesindedir:

  • LLM API'leri ve model sağlayıcıları (Providers).
  • Tool Calling ve Agent Loop mekanizması.
  • Çok ajanlı orkestrasyon (Multi-Agent Orchestration).
  • Context, State ve Memory yönetimi.
  • MCP (Model Context Protocol) ve A2A (Agent2Agent).
  • Ajan uygulamalarında test, Tracing ve Evaluation.
  • AI uygulamasını arayüzle paketleyip kullanıcıya sunma (Deployment).

Hedef Mezun ("Hero") Profili [Öğretim tasarımı]

Buradaki "Hero", sahte bir senior unvanı değil; hazır ders adımlarını birebir kopyalamadan, sınırları belli yeni bir problemi bağımsız olarak çalışan, güvenli ve ölçülebilir bir AI uygulamasına dönüştürebilme yeterliliğidir.

Bağımsız Mühendislik Akışı

Problemi tanımla → Basit Baseline kur → Tool ekle → Gerektiğinde ajanlaştır → Sonucu ölç → Hatayı Trace ile teşhis et → Arayüz oluştur → Dağıt (Deploy) → Sınırlamaları açıkla.

10 Temel Mezuniyet Yetkinliği

Yetkinlik Alanı Mezun Öğrencinin Göstereceği Somut Mühendislik Davranışı
1. Problem Çözümleme Tekil LLM Call, sabit Workflow ve otonom Agent arasında ezbere değil gerekçeli seçim yapar.
2. Temel Uygulama Geliştirme Model API'sini çağırır, yapılandırmayı (.env) koddan ayırır, Timeout ve API hatalarını yönetir.
3. Araç Entegrasyonu (Tools) Araç tanımlar, JSON Schema / tip girdilerini doğrular ve dönen sonucu güvenli biçimde işler.
4. Orkestrasyon (Orchestration) Kodla yönetim (Orchestration by Code), Agents-as-Tools ve Handoff arasındaki farkı yerinde uygular.
5. Veri Sözleşmeleri Pydantic ve Structured Outputs kullanarak bileşenler arası veri aktarımını tip güvenli hale getirir.
6. Context Yönetimi Sohbet geçmişi, kalıcı Memory, görev State'i, Tool sonuçları ve RAG (Retrieval) katmanlarını birbirinden ayırır.
7. Framework Seçimi Framework'leri sosyal medya popülerliğine göre değil; kontrol, State, Tracing ve ekip ihtiyacına göre karşılaştırır.
8. Gözlemlenebilirlik (Observability) Modelin "yaptım" diyen cevabına güvenmez; gerçekleşen Tool Call ve Trace kayıtlarını inceler.
9. Güvenilirlik (Reliability) Başarısızlık, sınırlı Retry, döngü sonlanma (Max Steps) ve Human-in-the-Loop onay yollarını tasarlar.
10. Teslim (Delivery) Çalışan uygulama, tekrarlanabilir test kanıtı ve bilinen sınırlamaları içeren anlaşılır dokümantasyon sunar.

4. Kursun Bütününü Taşıyan Zihinsel Model ve İngilizce Terimler Sözlüğü

[Öğretim tasarımı] Kursta göreceğiniz 10'dan fazla kütüphane ve framework (OpenAI Agents SDK, CrewAI, LangGraph, Deep Agents, Google ADK, AWS Strands, Pydantic AI, Microsoft Agent Framework, AutoGen, Semantic Kernel, Agno, Mastra) aslında tek bir temel mimariyi farklı sözdizimleriyle ifade eder:

Çekirdek Zihinsel Model

Bir ajan uygulaması; bir hedef (Goal), modele o anda verilen bağlam (Context), dış dünyayla etkileşen araçlar (Tools), uygulamanın durumu (State), karar-eylem yürütme döngüsü (Agent Loop), izin sınırları (Guardrails & Sandbox) ve sonlanma koşullarının (Termination) birlikte tasarlanmasıdır.

Şekil 1: Framework'lerden Bağımsız Evrensel Ajan Yürütme Mimarisi (Agent Harness & Loop)

Kritik Teknik Terimler Sözlüğü (İngilizce Terim → Türkçe Mühendislik Anlamı)

Aşağıdaki kavramlar kurs boyunca İngilizce halleriyle kullanılacaktır. Özellikle MCP ile A2A, Memory ile Context ve Framework ile Model kesinlikle aynı şey değildir:

İngilizce Teknik Terim Temel Mühendislik Anlamı Neyle Karıştırılmamalı?
Model (LLM) Verilen metin/token girdisinden olasılıksal olarak bir sonraki çıktıyı üreten dil modeli (GPT, Claude, Gemini, Llama vb.). Kendi başına kod çalıştıran veya internete çıkan uygulama değildir; sadece metin/JSON kararı üretir.
Tool / Function Calling Modelin "şu fonksiyonu şu parametrelerle çağır" talebi üzerine, sizin uygulamanızın gerçekten yürüttüğü tanımlı işlev. Model fonksiyonu kendi içinde çalıştırmaz; fonksiyon sizin Python/Node sürecinizde çalışır.
Agent Loop Model çıktısı → Araç çalıştırma → Araç sonucunu modele geri besleme → Yeni model çağrısı arasındaki `while` döngüsü. Tek seferlik soru-cevap (Single LLM Call) bir Agent Loop değildir.
Workflow Adımları, sırası ve geçiş koşulları önemli ölçüde geliştiricinin yazdığı kodla önceden belirlenmiş deterministik süreç. Her çok adımlı akış otonom Agent değildir; çoğu iş için Workflow daha güvenilirdir.
Orchestration Birden fazla ajanın, aracın ve alt görevin (Sub-Tasks) sırasının ve veri alışverişinin koordinasyonu. Sadece kodla değil; yönetici ajan (Agents-as-Tools) veya devir (Handoff) ile de yapılabilir.
State Devam eden bir görevin o andaki mevcut durumu (hangi adımda olunduğu, mesaj listesi, değişkenler, onay durumu). Uzun vadeli Memory'den farklıdır; yürütülen işin anlık çalışma fotoğrafıdır.
Memory Sonraki etkileşimlerde veya oturumlarda (Sessions) hatırlanmak üzere veritabanında/diskte saklanan bilgi. Bir bilginin Memory'de durması, her çağrıda modele gönderildiği anlamına gelmez.
Context Belirli bir model çağrısına o anda pencere içinde gönderilen seçilmiş bilgi (System Prompt + Seçili Geçmiş + RAG + Tool Sonuçları). Tüm veritabanını veya tüm geçmişi Context'e yığmak maliyeti artırır ve dikkat dağıtır.
Guardrail Girdi (Input), çıktı (Output) veya araç eylemi üzerinde uygulanan güvenlik/doğrulama sınırı ve kontrolü. System prompt içinde "lütfen yapma" demek gerçek bir Guardrail değildir.
Evaluation (Eval) Sistemin görevini ne kadar doğru, tutarlı ve eksiksiz yaptığının test setleri veya Evaluator ile ölçülmesi. Tek bir başarılı ekran görüntüsü almak Evaluation değildir.
Trace Çalışma sırasında gerçekleşen tüm LLM çağrılarının, araç girdilerinin/çıktılarının, sürelerin ve hataların adım adım iz kaydı. Kullanıcıya gösterilen son sohbet mesajı Trace değildir.
MCP (Model Context Protocol) Uygulamaların (Host/Client) araç ve bağlam sağlayan sunucularla (MCP Server) standartlaştırılmış iletişim protokolü. Bir ajan framework'ü veya ajanlar arası (A2A) sohbet protokolü değildir.
A2A (Agent2Agent) Farklı ajanların birbirlerinin yeteneklerini (Agent Cards) keşfedip doğrudan görev devretmesi ve iletişim kurması protokolü. MCP ajan-araç bağlantısı içindir; A2A ise ajan-ajan işbirliği içindir.
Agent Harness Ajanın uzun süreli görevleri yürütebilmesini destekleyen dosya sistemi, to-do listesi, alt ajanlar, Skills ve çalışma ortamı düzeni. Yalnızca çıplak LLM API çağrısı bir Agent Harness değildir.
Progressive Disclosure Yüzlerce aracı veya tüm SKILL.md dosyalarını modele tek seferde yüklemek yerine, ihtiyaç oldukça kademeli olarak açma tekniği. Bilgiyi tamamen gizlemek değil; Context Window'u verimli kullanmaktır.
