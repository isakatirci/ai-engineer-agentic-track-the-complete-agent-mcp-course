Bir LLM ile konuşurken aslında sürekli Python sözlükleri (dict), listeleri (list) ve JSON metinleri alıp verirsiniz. Model bir Tool Call yapmak istediğinde size bir Python nesnesi değil, JSON formatında bir metin (örneğin '{"city": "Istanbul"}') döndürür. Sizin kodunuz bu metni json.loads() ile ayrıştırır, doğrular ve ilgili Python fonksiyonuna iletir.

prep_01_python_json_schema.py — Tip Belirtimi, JSON Ayrıştırma ve Hata Yönetimi 
import json
from typing import Any
from pydantic import BaseModel, Field, ValidationError

# 1. Veri Sözleşmesi (Data Contract): Modelden veya dış API'den beklediğimiz yapı
class ToolCallInput(BaseModel):
    ticker: str = Field(..., min_length=1, max_length=10, description="Hisse sembolü, ör. AAPL")
    days: int = Field(default=7, ge=1, le=90, description="Kaç günlük veri çekileceği")

# 2. Tip belirtimli (Type-Hinted) ve hata korumalı bir Tool fonksiyonu
def fetch_price_summary(raw_json_arguments: str) -> dict[str, Any]:
    """Modelden gelen ham JSON argümanlarını doğrular ve sonucu sözlük olarak döndürür."""
    try:
        parsed_data = json.loads(raw_json_arguments)
        validated = ToolCallInput(**parsed_data)
    except json.JSONDecodeError as exc:
        # Model bozuk JSON üretirse uygulamayı çökertme, anlaşılır hata döndür
        return {"ok": False, "error": f"Geçersiz JSON formatı: {exc.msg}"}
    except ValidationError as exc:
        # Eksik veya sınır dışı parametre gelirse hatayı yakala
        return {"ok": False, "error": f"Şema doğrulama hatası: {exc.errors()[0]['msg']}"}

    # Normal iş mantığı (Simülasyon)
    return {
        "ok": True,
        "ticker": validated.ticker.upper(),
        "days": validated.days,
        "average_price": 194.50
    }

if __name__ == "__main__":
    # Başarılı senaryo
    print(fetch_price_summary('{"ticker": "msft", "days": 14}'))
    # Başarısız senaryo (days=-5 şema kuralını ihlal eder ama program çökmez!)
    print(fetch_price_summary('{"ticker": "msft", "days": -5}'))
Bu Bileşen Olmazsa Ne Bozulur?

Eğer json.loads ve Pydantic Validation adımını try/except olmadan doğrudan çalıştırırsanız, LLM'in ürettiği tek bir eksik tırnak işareti veya negatif sayı tüm Agent Loop'u Unhandled Exception ile yarıda keser.

HTTP Durum Kodları (Status Codes)

  • 200 OK: İstek başarılı, model yanıtı döndü.
  • 400 Bad Request: Gönderdiğiniz JSON şeması veya parametre hatalı (tekrar denemek hatayı çözmez!).
  • 401 Unauthorized: API anahtarı eksik, yanlış veya süresi dolmuş.
  • 429 Too Many Requests: Rate Limit veya kredi kotası aşıldı (kısa beklemeli Backoff gerekir).
  • 500 / 503 Server Error: Sağlayıcı tarafında geçici sorun.

A. Async Python (async / await) Mantığı

Bir LLM yanıtı ortalama 2 ile 10 saniye arasında sürer. Bu sürede bilgisayarınızın işlemcisi (CPU) aslında hiçbir iş yapmaz; sadece ağdan (Network I/O) yanıt gelmesini bekler. asyncio, bir modelden yanıt beklerken diğer ajanların veya araçların beklemeye takılmadan aynı anda (Concurrent) çalışmasını sağlar. Eşzamanlı ağ beklemesi ile işlemciyi bölen paralellik aynı şey değildir: burada kazanç, bekleme sürelerinin üst üste binmesidir.

prep_07_async.py — Üç sahte model çağrısını sırayla ve asyncio.gather ile
import asyncio
import time

async def fake_llm(name: str) -> str:
    await asyncio.sleep(2)  # ağ beklemesini taklit eder, CPU'yu meşgul etmez
    return f"{name} yaniti hazir"

async def main() -> None:
    started = time.perf_counter()
    for name in ("plan", "arastirma", "rapor"):
        await fake_llm(name)
    serial = time.perf_counter() - started

    started = time.perf_counter()
    await asyncio.gather(fake_llm("plan"), fake_llm("arastirma"), fake_llm("rapor"))
    concurrent = time.perf_counter() - started
    print(f"sirali={serial:.1f}s eszamanli={concurrent:.1f}s")

if __name__ == "__main__":
    asyncio.run(main())
sirali=6.0s eszamanli=2.0s

Hazırlık Geçiş Kriteri: Öğrenci temiz bir ortamda projeyi kurabilmeli, API anahtarını koddan ayırabilmeli, bir JSON girdisini okuyabilmeli ve başarısız bir isteği anlaşılır biçimde yönetebilmelidir. Aşağıdaki gate_check.py betiğini çalıştırıp çıktısını doğruladığınızda 1. Haftaya tamamen hazırsınız demektir:

gate_check.py — Hazırlık Geçiş Doğrulama Betiği 
import os
import json
import urllib.request
import urllib.error
from dotenv import load_dotenv

def verify_readiness(raw_config_json: str) -> dict:
    # 1. Ortam değişkenlerini (.env) yükle ve koddan ayrıldığını doğrula
    load_dotenv()
    api_key = os.getenv("OPENAI_API_KEY", "")
    has_clean_key = bool(api_key and api_key.startswith("sk-") and len(api_key) > 20)

    # 2. JSON girdisini güvenli ayrıştır
    try:
        cfg = json.loads(raw_config_json)
        timeout_sec = int(cfg.get("timeout", 5))
    except (json.JSONDecodeError, ValueError) as err:
        return {"ready": False, "stage": "json_parse", "reason": str(err)}

    # 3. Dış servis çağrısında Timeout ve Hata yönetimini doğrula
    req = urllib.request.Request("https://httpbin.org/status/429", method="GET")
    try:
        with urllib.request.urlopen(req, timeout=timeout_sec) as resp:
            status = resp.status
    except urllib.error.HTTPError as http_err:
        # 429 hatasını çökmeden yakalayıp anlamlandırabilmeliyiz
        handled_error = f"HTTP {http_err.code} yakalandı: Rate limit / kota kontrolü aktif."
    except Exception as net_err:
        handled_error = f"Ağ/Timeout hatası güvenli yakalandı: {net_err}"
    else:
        handled_error = f"Beklenmeyen durum: {status}"

    return {
        "ready": True,
        "env_key_configured": has_clean_key,
        "timeout_configured": timeout_sec,
        "error_handling_proof": handled_error,
    }

if __name__ == "__main__":
    result = verify_readiness('{"timeout": 4}')
    print(json.dumps(result, indent=2, ensure_ascii=False))
